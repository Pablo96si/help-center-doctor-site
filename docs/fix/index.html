Fix Center

Fixes turn findings into changes. Every change goes through the same apply dialog, whether it comes from a finding, from find and replace, from a bulk action or from the link map. Fixes need the Pro or Business plan.

Findings without a fix (stale articles, negative votes, short bodies, heading problems and so on) open the Guide editor instead.

Fixing many at once

Select findings that use the same kind of fix and click Fix selected. Fixes that need input (a new URL, alt text, labels, a section) apply the same input to every selected finding, so pick findings that share the same target. Several fixes on one article are merged into a single write.

The apply dialog

  1. The dialog lists every change, one row per article and language, with a word-level diff under Show changes. Untick anything you do not want.
  2. If any change rewrites a title or body, you are asked to confirm that the articles do not use content blocks, or that you accept them being converted (Guide Enterprise only). You can silence this in Settings if your help center does not use content blocks.
  3. If any change archives an article, you are asked to acknowledge that undo cannot restore it; you can restore it in Guide under Manage articles, Archived.
  4. Click Apply. A snapshot file of the affected articles is downloaded first, then the writes run one by one. Keep the tab open.
  5. The result shows how many changes were applied and how many failed. The app stops after five failures so a permissions problem does not burn through the batch; the snapshot covers the successful ones.

Snapshots

A snapshot is a JSON file with the previous title, body and status of every article about to change. It is saved to your downloads folder before anything is written. You can restore it any time from Activity with Restore from snapshot file, which writes the saved content back. Snapshots are your files; the app does not keep them anywhere else.

Undo

The Activity screen keeps the last 20 change sets of the session. Undo restores the previous content and settings of the affected articles, one write per article. If someone edited an article after the change, undo overwrites that edit with the snapshot content, so check first. The undo stack is lost when you close the app; snapshot files are permanent.

Read-only roles

If your Zendesk role cannot edit articles, the apply dialog says so and does not run. Ask a Guide admin to apply the change, or export your settings so they can reproduce your filters.
