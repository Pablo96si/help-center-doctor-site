Documentation

Help Center Doctor is a Zendesk Marketplace app that lives in the left navigation bar of Zendesk Support. These pages walk through every screen. If you would rather click around first, the live demo runs the same app on sample data.

Install in five minutes

  1. Open the Help Center Doctor listing on the Zendesk Marketplace and click Install. You need to be a Zendesk admin to install apps.
  2. Choose the account, pick a plan (Free, or Pro with a 14-day trial) and confirm. You can restrict the app to certain roles or groups on the same screen.
  3. In Zendesk Support, click the Help Center Doctor icon in the left navigation bar. If you do not see it, reload the page.
  4. Click Scan now. The scan reads your help center with your own permissions and never changes anything.
  5. Open Findings and start with the critical ones.
No setup, no account, no API key

The app uses the Zendesk session you are already signed in with. There is nothing to configure before the first scan.

Who can do what

Scanning works for any agent who can read the help center. Applying fixes, replacements and bulk actions needs a role that can edit the articles involved (a Guide admin, or an agent in the right permission group). The app reads your role when it opens and shows a read-only banner if it cannot write; you can still scan, review, preview and export.
